# Ventoy Themes

A collection of Ventoy themes for customizing the boot menu used with ISO files.

## Installation

1. Download the ZIP archive for the theme you want to use.
2. Extract the archive. It should contain a directory named `ventoy`.
3. Copy the extracted `ventoy` directory to the root of the USB drive that contains your ISO files.
4. Safely eject the drive, boot from it, and confirm that the selected theme is displayed.

Keep a backup of any existing `ventoy` directory before replacing it. If the theme does not appear, confirm that the directory is at the USB root and that the files were not copied into an extra nested folder.

## Contributing

Add new themes in their own clearly named directory and include a preview image when possible. Keep archives free of unrelated personal files and verify the theme on a test USB drive before submitting it.
